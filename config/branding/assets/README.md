# Redstone branding assets

Store original Redstone-owned assets in the subdirectories below.

- `logo/`: SVG/PNG logos and monochrome variants.
- `icons/`: application, system and symbolic icon assets.
- `wallpapers/`: source artwork and generated wallpaper variants.
- `boot/`: bootloader artwork and boot splash assets.
- `login/`: display-manager/login-screen artwork.
- `installer/`: installer welcome and slideshow artwork.

Keep source artwork editable and record licenses/attribution for every imported asset. Do not copy upstream artwork without checking its license. The current generated desktop wallpaper is produced by `scripts/build.sh`; the remaining integrations are planned.
