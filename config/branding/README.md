# Branding

The Redstone identity and palette are defined in `branding.toml`. Original artwork belongs under `assets/`:

- logos and marks
- application/system icons
- wallpapers and source artwork
- bootloader and boot splash assets
- login/display-manager assets
- installer artwork
- system sounds, fonts and cursors (with licensing notes)

The initial desktop theme and wallpaper are generated by `scripts/build.sh` inside the pinned Omarchy source tree. Boot, login, icon, cursor, font and sound integrations remain planned. Keep source artwork editable and record licenses/attribution for imported assets.
