# Omarchy patches

Place focused, reviewable `.patch` files here for Redstone-specific changes to the pinned Omarchy checkout.

Patch files are applied by `scripts/build.sh` after upstream sources are checked out. Keep patches ordered and narrowly scoped. Document the upstream file/path, reason, expected behaviour and how the patch was tested.

Do not place generated theme assets here. Do not patch upstream behaviour when a supported configuration mechanism exists.
